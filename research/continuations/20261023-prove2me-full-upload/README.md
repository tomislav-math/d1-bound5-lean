# Private Prove2Me transfer

The completed local Lean verification is recorded in [STATUS.md](../../../STATUS.md). The Prove2Me transfer is a separate, ongoing operation.

See [the dated transfer snapshot](TRANSFER_SNAPSHOT.json) for counts and the [mission graph](https://prove2.me/missions/No_Diophantine_sextuples_in_rings_of_integers_of_imaginary_quadratic_fields/graph) for connected statements and accepted reductions. The account must have access to the private mission. Enable **Show definitions** to display definition nodes.

[My Submissions](https://prove2.me/my-submissions) lists submitted proofs; bare statement and definition registrations do not appear there.

For the current bulk transfer, source metadata records the repository URL and its original Lean file path, line range, and SHA-256. The [source compatibility record](../20261023-github-closeout/PROVE2ME_LINK_COMPATIBILITY.json) checks those references against the verified source inventory.

This repository snapshot deliberately excludes API credentials and the mutable upload ledger.
