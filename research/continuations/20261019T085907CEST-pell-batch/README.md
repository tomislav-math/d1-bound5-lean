# Bounded Pell certificate batch

This directory preserves a reviewed serial batch of unchanged working sources and their actual pinned compilation and verification receipts. It is a research snapshot, not a new accepted root or a proof of MainStatement.

Read TARGETS.json for the exact twelve modules, CERTIFICATE_SCOPE.json for the field and pair coverage, PRE_BUILD_SOURCE_REVIEW.json for pre-build source hashes, and BATCH_RESULTS.json for actual compile results. TARGETED_REPLAY_RECEIPTS.json records the exact-type/transitive-axiom audit and twelve installed SAME-kernel checks after they are executed. A prepared file is not a verification pass.

All working modules are copied byte-for-byte before their guarded builds. The unchanged continuation_driver_capacity.py is reused under the project ownership/intake locks, with max_parallel=1 and no queue changes. No mathematical source is rewritten in this batch. The inherited Git index entry is preserved and is not part of this proof unit.

Snapshot files in this directory retain those declarations for preservation only and must not be imported alongside duplicate archived versions. Compile the working modules from the pinned project, not this directory as a new source root.
