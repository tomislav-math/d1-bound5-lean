# Sparse floor certificates

These are untrusted inputs for a new optional proof backend. No original Lean
module is replaced, and none of these generated modules has been compiled.

`generate_floor_witnesses.py` reads frozen original vertex declarations and
current sieve masks, checking all pinned hashes. It re-enumerates all
8,063,266 same-color pairs by exact small-residue bitsets. Of the 68,640
modular survivors, 40,026 satisfy the independently proved negative-integer
divisibility rejection. The other 28,614 receive one natural floor witness:
12,443 positive real, 16,165 negative scaled, and six integer-norm witnesses.
No quadratic-field root search is used.

Each `generated/SmallPairFloorWitnessDataN.lean` defines
`D1Bound5.PairFloorWitnessN.leftRows` and `rightRows : List (List Nat)`.
Color zero is left, color one is right; original vertex order is retained.
There is exactly one witness list per head, including the final empty row.
Within each row, witnesses occur in full remaining-tail order, only when the
actual distinct pair survives the cached sieve and cheap divisibility guard.
Coordinates, modular signatures and color masks are not copied into the Lean
witness modules. The companion JSON retains original indices and dispositions
for independent auditing.

The generic checker being developed by Bennett must compare every head with
the entire remaining tail, consume one witness only in the residual branch,
reject missing or extra witnesses, and reject missing or extra head rows.
Any later chunking must preserve the full tail at each head, including pairs
whose later endpoint lies outside that chunk. The checker must retain the
existing exact vertex coverage and canonical signature validation. It should
derive the original independence Boolean, so downstream triangle and full-ring
theorem statements remain unchanged. Python enumeration is never a premise.

The analytic agent's proposed primitive is
`QuadInt.floorObstructionBool z (k : Nat)` with soundness under positive
discriminant. For real positive `m`, check `k² < m < (k+1)²`. For negative
real `m`, check `q*k² < -m < q*(k+1)²`, with `q=nu` at trace zero and
`q=4*nu-1` at trace one. For a nonreal radicand, check that its integer norm
lies strictly between those squares. All six nonreal witnesses use this last
branch. Zero and unsupported models must be rejected by the checker.

Reproduction from the project scratch root:

```sh
python sparse_floor_next/generate_floor_witnesses.py
python sparse_floor_next/verify_floor_witnesses.py
```

The verifier does not import the generator and calls no square-root routine.
It parses the emitted Lean lists, uses the separately pinned original graph
pair sets, recomputes coordinate products, and checks every strict inequality
and exact witness exhaustion. The earlier diagnostic independently proved
equality of those graph pair sets with exhaustive current-mask enumeration.

The generator accepts explicit source, manifest, sieve and output directories,
plus selected rows, for portable staging. It writes only its output directory.
The output manifest pins all source data and generated bytes. Performance and
kernel acceptance remain the coordinator's responsibility.
