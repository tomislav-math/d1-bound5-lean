# Preserved local research and verification history

Snapshot requested by the author on 16 October 2026 while recovering all
previously unpushed formalization work. This directory is NOT part of the
accepted Lean dependency graph and is not imported by D1Bound5.lean.

`trials/` preserves the 61 existing exploration sources byte for byte,
including obsolete and failed attempts. A trial may fail to compile, use
provisional tactics, or duplicate an accepted theorem. No acceptance or
independent verification is implied by archiving it.

`logs/` preserves the 317 existing text logs and local receipts. A line
saying that replay started is NOT a successful completion receipt. Logs
of failed runs remain failed. Use the matching final records and exact
source hashes, not a filename or a historical claim, to judge a proof.

MANIFEST.json maps every archived file to its original relative path,
size and SHA-256. Originals were left unchanged. Compilation outputs,
dependency caches, other projects, credential stores and the frozen
external manuscript were not copied. The scoped credential-pattern
scan found no matches; it is not a general guarantee about all secrets.

Current accepted definitions and proofs remain under D1Bound5/, and their
current verification scope is documented in STATUS.md and records/.
