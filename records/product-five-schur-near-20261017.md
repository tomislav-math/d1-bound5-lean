# Product-five Schur proximity: proved quantitative interface (17 October 2026)

The accepted root module `D1Bound5/ProductFiveSchurNear.lean` contains five new theorems. All arguments are over complex matrices with the ordinary algebraic transpose, not the Hermitian adjoint.

1. `four_all_entries_operator_norm_lt`: for any complex 4x4 E with all entries of modulus strictly less than delta > 0, its L2 operator norm is < 4 delta. Proof: split into the diagonal matrix and a zero-diagonal remainder; apply the previously verified three-matching estimate to the latter.
2. `productFive_schur_near_of_entrywise`: if ||F-H|| <= 11/96 and each entry of G-F has modulus < 9/100, then ||G-H|| < 4(9/100)+11/96 = 1139/2400 < 1/2, where H=(J-I)/2.
3. `productFive_schur_scalar_correction_lt`: if ||d|| >= 54, ||wi/d||,||wj/d|| < 1/18 and ||vi||,||vj|| < 3/4, then ||(wi*vj+vi*wj)/d + vi*vj/d^2|| < 1/12+1/5184 < 9/100.
4. `productFive_schur_near_of_coordinate_bounds`: combines the preceding inequalities and the exact pre-existing definition of `productFiveSchur` to show ||G-H|| < 1/2 under the explicit quantitative hypotheses for F,v,w,d. The theorem does NOT assume symmetry or invertibility of F.
5. `productFive_prefix_coordinate_div_lt_eighteenth`: from ordered moduli ||t0||<=...<=||t4||, ||t1||>=3 and 2||t1||||t2||||t3||<||t4||, proves ||t_i/t4|| < 1/18 for each of the first four coordinates. This is the exact scalar interface needed for w/d.
